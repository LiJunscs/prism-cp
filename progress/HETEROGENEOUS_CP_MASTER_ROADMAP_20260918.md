# Hybrid 序列与层联合动态 CP Roadmap

当前研究固定 GDN:GQA=3:1。联合选择完整输入的组批、分层 CP、rank 组与 token 放置，在完整训练显存预算下最小化更新时间。N 为未修改调度逻辑的 Megatron 原生 dynamic CP，并保留连续 GDN 段布局；二维拥有全部现有执行自由度。

事实与结果只以 [当前归档](ARCHIVE-20261016.md) 为准。本页是研究优先级，GPU 仍暂停；[H100 迁移](H100_MIGRATION.md) 不授权新运行。

数据、二维性能模型与调度器的对应关系，以及可运行的 CPU 接手检查，见 [CODEX_HANDOFF.md](CODEX_HANDOFF.md)。历史 CP 扩展性原始表随代码保留。

## 已有核心结论

- 224Ki＋4Ki：可变 N-K14 比固定 N-K24 快，二维在可变 N 之上仍增加约 29.3% 吞吐，allocated 只增加约 3.4%。容量适配与二维收益均存在。
- 256Ki 的 72 条有限容量消融：K16/K24/K32 内 N-K16 最好，二维增加 24.09% 吞吐；大容量 N 被实际显存预算拒绝。
- 568 条短批重打包：降低约 12GiB allocated，仍保留相对 N-K16 的 24.82% 吞吐提升。
- CPU 模型认为 192Ki/208Ki 存在应选可变 N 的输入。实际在线 N/二维选择未接入。

## 按最小实验推进

1. **在 H100 建立同硬件对照。** 保留正例、不规则长度与选择 N 的三个问题，先确认新拓扑下固定 N、可变 N、二维的排序。复用相同输入/训练合同，输出独立保存。旧 H800 容量和响应只是初始候选，不能假定为 H100 最优。
2. **检验评分模型的独立价值。** 固定候选集合和执行器，比较计算量评分与含算子 CP 响应、路由、完整显存的评分。容量消融衡量自由度；这项消融衡量能否选对计划。
3. **实现实际在线选择。** 针对随机 batch 分布，在可变容量 N 与二维之间选择，计入决策和切换成本，以总有效 tokens/总墙钟时间评价。缓存区分形状、算子与拓扑。
4. **补充机制验证。** 单机只需一个合适输入下可变 N/二维两个项，判断没有跨节点瓶颈时收益是否仍在；不把现有需要 CP16 的 N-K14 直接搬到 8 卡。

保持完整训练、统一实际显存保护与真实 N。模型预算和实际显存分开报告；不把偏好规则拒绝写成物理不可行。当前 α=2 的显存交换偏好使用双方共同固定参考，物理预算独立生效。

## 方法与未完成部分

组内 S=ΣL、Q=ΣL²；GQA 时间可写为 `(aQ+bS)/p+R_GQA`，GDN 为 `cS/p+R_GDN`。R 表示输入、内核与拓扑相关响应；已含通信不重复计费。联合评价组间最大时间、边界搬运及跨 F/B 的存活显存，不能由某层局部加速直接推出整步收益。

当前 H800 冻结模型部分系数仍有误差，未验证广泛输入排序和在线净收益。模型与接口可后续扩展稀疏注意力，但后续近期实验继续固定 3:1。独立 HybridModel 类集成、训练正确性和长期收敛属于后续工程/论文证据，不在此次清理中启动额外 GPU 任务。
