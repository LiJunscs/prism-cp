## 最新 GPU 结果：224Ki＋4Ki

输入为 8×224Ki＋64×4Ki，共 2Mi tokens。两节点各 8 张 H800；H4096、FFN16384、vocab32768，BF16，TP=PP=1，无重计算；GQA Q32/KV8/head128，GDN16×128、conv4。每项 5 个完整更新，前 2 步预热，后 3 步按所有 rank 的最大更新时间计量。

|方案|完整更新时间 s|allocated GiB|required GiB|
|---|---:|---:|---:|
|固定 N-K24|17.954366|57.0173|63.4223|
|可变 N-K14|16.089427|39.1710|46.4621|
|N-K28|第二步预算拒绝，无计量速度|64.1243|72.2885|
|二维|12.444081|40.4919|48.5553|

容量调整本身提高吞吐约 11.6%；在此基础上二维再提高约 29.3%，allocated 只增加约 3.4%。相对固定 N-K24，二维吞吐提高约 44.3%。这组实测说明收益不能仅用改变 N 的容量解释。N-K28 超过共同 71.178833GiB 预算，不能引用其预热步作速度比较。

矩阵原计划为 3 个输入、8 个独立项：224Ki＋4Ki 的 N-K24/K14/K28/二维，不规则长序列＋8Ki 的 N-K24/二维，192Ki＋4Ki 的 N-K24/二维。后两组固定与可变 N 复用同一项；固定 K24 是该三输入分布下两种响应模型共同选出的容量。

累计 6 次 GPU 启动、17 次完整更新、1 次 GPU 重试。第一次 N-K24 在初始化因外部进程占约 74.84GiB 而 OOM；恢复后完成上表。不规则 N-K24 又因另一进程占约 27.23GiB 而在首个完整更新前 OOM，随后按用户要求暂停。这两次不是独立的 N 训练显存结论。不规则 N 需要有效重测，不规则二维和 192Ki 两项未启动。

证据：`experiments/sequence_dynamic_cp/results/random_batch_capacity_gpu_20261016_r1/`。保留 matrix、comparison、supervision、输入、计划、原始协议、压缩逐 rank 完整更新记录及失败日志。H100 上使用新输出目录与新对照，不能将 H800 的 N 与 H100 的二维计算速度比。

## 已完成的支持证据

|输入|原生 N 时间 s|二维时间 s|吞吐提升|allocated 增长|
|---|---:|---:|---:|---:|
|8×256Ki＋64×4Ki，72 条|18.252830|14.708877|24.09%|3.34%|
|56×256Ki＋512×4Ki，568 条|126.454210|101.306751|24.82%|3.43%|

72 条在已测 K16/K24/K32 中 N-K16 最好：K24 更慢，K32 首步 required 77.381764GiB，超共同预算。证据为 `results/native_capacity_ablation_20261016_r1/`。

568 条仅将纯短 CP1 批由 4×96S＋64S 改为 7×64S，使 allocated 从 56.638 降到 44.591GiB，步时只增加约 0.33%；保留了主要性能收益。证据为 `results/joint_cp_memory_validation_20261016_r2/`。

原始 N 与二维分别保存在 `results/native_n_remeasure_20261016/`、`results/joint_cp_two_20261015/`，包含 1136 条的大纯短包测量；1136 条显存优化未做 GPU 验证。上述 results 路径均相对 `experiments/sequence_dynamic_cp/`。

完整训练包含输入/labels/mask、MLP、输出头/loss、F/B、gradient finalize、norm/clip、非零 Adam 和参数同步。两侧仅首次 finalize 前释放一次空闲 allocator 缓存。比较全运行全卡最大 allocated；reserved 单独报告。真实准入为 required（含观测外部占用）不超过 `min(0.9×total,total−8GiB)`。这些是冻结计划短运行，在线开销与长期收敛尚未验证。

## 可复用分析与下一步

`random_batch_capacity_analysis.py` 复用 11 个可评分的 3:1 输入，以 `ceil_to_32_tokens(L/p)` 加 K16 回退生成可变容量候选，已出现 K15.5Ki；不强制整数 Ki 或 2 的幂。11 输入等概率的物理模型预算下最佳固定 K26，可变 N 预测吞吐增加 3.20%–11.17%，再允许二维额外增加 24.07%–26.07%。范围对应两种 CP16 模型政策，不是置信区间。这里随机抽取完整长度多重集合，不是全面的逐样本 IID 实验。

完整缓存保存在 `results/random_batch_capacity_20261016_r1/` 和 `results/joint_advantage_search_20261016_r1/analysis.json`。224Ki 正例已实测；不规则长度正例及 192Ki 选择 N 的对照尚缺有效结果。

H100 上优先回答：新拓扑下二维能否超过可变容量 N；随后做同一候选集合上的评分模型消融，再接在线选择并计入规划/切换成本。单机仅作为排除跨节点因素的补充，不加入当前最小必做矩阵。稀疏注意力与独立 HybridModel 类不是此次迁移前置项。
