## 性能评价与硬件数据选择（用户确认）

性能收益按分配 GPU 数归一后的每卡有效 TFLOP/s 或 MFU 判断，延迟仅作辅助指标。对固定有效工作量 F、卡数 p、时间 T：`TFLOP/s/GPU = F/(p*T*10^12)`，`MFU = F/(p*T*单卡理论峰值)`。同硬件同工作量时，比例中的 F 和单卡峰值抵消：`效率比 = (p_old*T_old)/(p_new*T_new)`。因此 CP8→16 的比例为 `T8/(2*T16)`：时间未减半是效率损失，恰好减半是效率持平，少于一半才提高每卡效率。这里报告的是相对每卡 TFLOP/s／MFU，未定义完整 FLOP 口径与单卡峰值前不编造绝对 MFU。

完整调度计划计入所有分配卡（含空闲等待）和全部有效输入工作，在线评价还计入规划与切换。当前 N/二维完整训练对照使用相同输入与固定 16 卡，因此其时间排序仍与每卡有效 TFLOP/s／MFU 排序等价；局部模块从 8 卡换到 16 卡的延迟比不能直接作同样解释。

CP8 聚合取两个节点各自 rank-max 迭代中位数的中位数：GQA 463.346039ms、GDN 26.383841ms；CP16 为 GQA 305.552673ms、GDN 14.369376ms。该聚合用于统一节点估计，不能当成并发两组时实测的全 rank 最大值。**GDN 的每卡效率保持率为 91.81%，高于 GQA 的 75.82%；两者均未达到 100%。** 以 L₀=256Ki、S=ΣL、Q=ΣL² 和原有有效 FLOP 口径 W 写为：

```text
T_o(S,Q,p) = A_o,p * W_o(S,Q)/W_o(L₀,L₀²)
C_o,p = W_o(L₀,L₀²)/(p*A_o,p)
T_o(S,Q,p) = W_o(S,Q)/(p*C_o,p)
```

GQA 的 W 含 S、Q，GDN 的 W 含 S，详式见 [执行与模型合同](../experiments/sequence_dynamic_cp/JOINT_CP.md)。单长度数据不足以分别拟合固定、线性与平方项；跨长度和 packing 的工作量缩放明确标为未验证。节点内 CP1/2/4 暂按 CP8 的每卡效率外推，attention CP>16 拒绝；MLP、输出头、路由、更新与完整显存保留解析假设。锚点已包含模块 CP 通信，不再重复叠加通信项。

独立二维求解器经 `joint_cp_search.py --hardware H100` 或显式模型路径加载新响应。保留组批、各层 CP、MLP 放置和完整显存约束，不硬编码 GDN CP16/GQA CP8。固定完整输入和分配卡数时，最小化完整时间等价于最小化全部分配卡的 GPU·时间；结果新增 `resource_metrics`，报告预测 GPU·ms 和声明口径下的每卡有效 TFLOP/s，未假设单卡峰值，绝对 MFU 留空。

独立 CPU 检查从 16 份原始 rank 记录复算四个锚点，与模型精确一致。两个 16 卡、8 层的小输入求解/replay 通过：`[256Ki,4Ki]` 选 CP16 packed，预测 1329.405ms；`[128Ki,128Ki]` 选两个 CP8 组，预测 898.903ms。两者均保留原模型显存约束，bounded 求解没有全局最优证书，预测不是 GPU 准入或性能实测。后者还经真实 CLI 验证 `result.json`、`replay.json`、`executor.json` 和硬件配置传递。

13 个冻结候选的回溯重评分未覆盖原先评分文件。224Ki 在模型可行候选中选 N-K14（预测 9.380s，实测 6.519s），192Ki 选 N-K24（预测 6.732s，实测 4.815s），均与已测最快有效项一致。**剩余误差保留：**不规则输入预测首选 N-K24（9.123s）仍被真实显存 guard 拒绝；在实际有效项中模型预测 K20 比 K16 快，而实测 K16 略快。新模型已纠正核心 CP 响应，完整训练的绝对时间、细微排序和显存准入仍未充分校准，不能将回溯结果当成广泛输入验证成功。

本次只做 CPU 工作。相关模型、求解、scale 与显存选择测试共 30 项通过；独立验证另完成 H800 response 5 项测试与接手检查，历史冻结分数/原生计划不变。证据位于 `results/h100_model_validation_20261016_r1/`：`anchor_oracle.py/.json`、`validate_model.py`、`model_validation.json`、两份 solver/replay、`policy_checks.json`、`regression_checks.json`、`cli_validation.json`。未新增 GPU 启动，未修改训练执行器、Megatron 或环境。

## H100 二维优势场景搜索：33 个组合，尚无可靠的大幅收益候选
